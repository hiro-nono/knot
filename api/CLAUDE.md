# プロジェクト概要

knot/apiでは、発信者と受信者、それぞれにAIエージェントを提供するAPIです。

- 発信者 × AI：発信したい情報を対話によって整理・確定する
- 構造化された情報：確定した情報を正しい情報として保存する
- 受信者 × AI：構造化された情報を受信者に適した形式で表示し、質問にも回答する

本システムでは、情報と表示形式を分離し、必要なときにAIが最適な表示を生成します。

## 正しい情報

Source of Truth
├──  Identity      ：何についての情報か
├──  Fact          ：何が事実なのか
├──  Schedule      ：いつ・期間
├──  Condition     ：どんな条件で何が起こるか
└──  Interaction   ：受信者に何をしてほしいか
