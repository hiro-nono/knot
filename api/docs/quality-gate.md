# 品質ゲート

コード生成後、以下の観点を満たしていることを確認する(Stopフックで自動チェックされる)。

## 必須項目
- [ ] 新規追加した公開関数にはユニットテストがある
- [ ] アーキテクチャ依存ルール(architecture.md)に違反していない
- [ ] 型エラー・lintエラーがない
- [ ] マジックナンバー・ハードコードされた文字列がない(定数化されている)

## 保守性の観点
- [ ] 1関数が50行を超えていない
- [ ] 同じロジックが3箇所以上重複していない

## 判定
違反があれば `block` を返し、該当ファイルと違反理由を具体的に指摘すること。
